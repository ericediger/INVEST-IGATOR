- `scripts/verify-local.py`: reads data folder, port, node binary and active release from the installed LaunchAgent; dropped the assertion that the workspace holds the seven originally seeded tickers.
- `scripts/enable-trusted-lan.py`: rewritten from a one-off 1.0.1 deployment into `enable-trusted-lan.py <address> <subnet>` / `off`. Validates a private IPv4 address inside a strict subnet, binds the address to prove it exists, backs up the plist under `service-config-backups/`, restarts the app, verifies every address serves the unchanged workspace and the expected access label, and restores the previous plist on failure.

- `docs/API.md`, `docs/ARCHITECTURE.md`: the LAN address is now described as the configured `RESEARCH_LAN_ADDRESS` / `RESEARCH_TRUSTED_SUBNET`.
- `README.md`: the macOS service paragraph now describes the scripts instead of warning about them.
- Version 1.5.2 in `package.json`, `package-lock.json` and `server/app.js`.
